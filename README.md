
# Student Management System

## Project Description
A simple Python application to manage student records.

## Features
- Add Student
- View Students
- Search Student
- Delete Student
- Validate Student Marks

## Technologies Used
- Python
- Unittest
- Docker
- Git and GitHub
- GitHub Actions

## How to Run

```bash
python app.py
```

## How to Run Tests

```bash
python -m unittest -v
```

## Docker Build

```bash
docker build -t student-management .
```

## Docker Run

```bash
docker run -it student-management
```
